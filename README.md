# Server Mothalali

Server management suite featuring:
- **Discord Server**: Bot and Discord integration for server operations and notifications.
- **SSH Server**: Secure remote server execution, automation, and management.
- **Web Interface**: Web dashboard and UI to monitor and control services.

## Project Structure

```
server-mothalali/
├── discord-server/     # Discord bot & interaction handlers
├── ssh-server/         # SSH connection manager & remote command runner
└── web-interface/      # Web dashboard & frontend UI
```
